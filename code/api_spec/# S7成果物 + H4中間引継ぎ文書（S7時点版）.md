# Part B: §6 MISRA連携API（CLI仕様）ドラフト

## 6.1 概要

StaTable の MISRA チェックは、**`cppcheck` + MISRA addon を外部プロセスとして呼び出す**方式を採用。**C コードとリンクしない**（引継ぎ書 §2.2 の前提と一致）。

| 項目 | 内容 |
|------|------|
| チェッカー | `cppcheck` 2.x + `--addon=misra` |
| 出力形式 | XML (`--xml --xml-version=2`) |
| 実行方式 | CLIツール（Python 3.12） |
| ビルド失敗 | **しない**（informational only） |
| 前提条件 | `cppcheck` が `PATH` に存在すること |

**重要**：`cppcheck + MISRA addon` は **MISRA C:2012 の公認チェッカーではない**。StaTable は「対応」「評価」と表現し、「準拠」とは表現しない。

---

## 6.2 CLIツール1：`tools/run_misra_check.py`

生成 C コードに対して cppcheck を実行し、Markdown サマリを出力する。

### シグネチャ

```bash
python tools/run_misra_check.py --root <DIR> --out <DIR> [--suppressions <FILE>]
```

### 引数

| 名前 | 型 | 必須 | デフォルト | 説明 |
|------|-----|------|-----------|------|
| `--root` | `str` | ○ | – | 生成Cコードのルートディレクトリ。`*.c` を再帰検索 |
| `--out` | `str` | ○ | – | 出力ディレクトリ |
| `--suppressions` | `str` | – | `misra/suppressions.txt` | 抑制リストファイル |

### 出力ファイル

| ファイル | 内容 |
|---------|------|
| `summary.md` | MISRA ルール別集計 + Non-MISRA 警告 + Next Steps |
| `cppcheck_raw.xml` | cppcheck の stdout（XML） |
| `cppcheck_stderr.txt` | cppcheck の stderr（XML含む場合あり） |

### 終了コード

| コード | 条件 |
|--------|------|
| 0 | 正常終了（違反があっても0） |
| 1 | `root` 不在 / `cppcheck` 未インストール / タイムアウト |

### cppcheck 呼び出しコマンド

```bash
cppcheck \
  --addon=misra \
  --enable=warning,style,performance,portability \
  --inline-suppr \
  --error-exitcode=0 \
  --xml --xml-version=2 \
  --quiet \
  --suppressions-list=<FILE> \
  -I <root>/include -I <root>/common -I <root>/src \
  <files...>
```

### 使用例

```bash
cd code
python tools/run_misra_check.py --root output --out misra_report
```

### `summary.md` の形式（抜粋）

```markdown
# MISRA C Check Summary

> **Informational only.** This report does not fail the build.
> cppcheck + MISRA addon is not a certified MISRA checker.

## Overview
- Files analyzed: 14
- Total MISRA rule hits: 10
- Distinct MISRA rules hit: 4
- Non-MISRA warnings: 9

## MISRA rules (by frequency)
| Rule | Count |
|------|------:|
| misra-c2012-11.5 | 4 |
| misra-c2012-8.4  | 3 |
| misra-c2012-18.4 | 2 |
| misra-c2012-15.7 | 1 |
```

### 制限事項

- `cppcheck` の実行時間上限は **600秒**（`timeout=600`）
- `cppcheck` 未インストール時は **終了コード1** で停止
- XML解析エラー時は警告ログのみで**空のサマリ**を出力

## 6.3 CLIツール2：`tools/analyze_misra_impact.py`

MISRA 違反を **責任 codegen ソース** にマッピングする。

### シグネチャ

```bash
python tools/analyze_misra_impact.py --xml <FILE> --out <FILE> [--csv <FILE>]
```

### 引数

| 名前 | 型 | 必須 | デフォルト | 説明 |
|------|-----|------|-----------|------|
| `--xml` | `str` | ○ | – | cppcheck XML（`cppcheck_raw.xml`） |
| `--out` | `str` | ○ | – | Markdown 出力先 |
| `--csv` | `str` | – | `''` | CSV 出力先（省略時はCSV出力なし） |

### 出力ファイル

| ファイル | 内容 |
|---------|------|
| `<out>` | 影響分析 Markdown |
| `<csv>` | `codegen_source,rule_id,count` の CSV |

### マッピング規則（`GENERATED_TO_CODEGEN`）

生成Cファイル名の部分文字列 → 責任 codegen ソースのリスト。

| 生成ファイルパターン | 責任 codegen ソース |
|-------------------|-------------------|
| `statable_role_functions` | `role_function_generator.py`, `code_templates.py` |
| `statable_transitions` | `transition_generator.py`, `code_templates.py` |
| `statable_types` | `struct_generator.py`, `enum_generator.py`, `variable_generator.py`, `code_templates.py` |
| `statable_init` | `variable_generator.py`, `c_code_generator.py` |
| `statable_event_queue` | `event_queue_generator.py` |
| `statable_interrupt` | `interrupt_generator.py` |
| `statable_timer` | `timer_generator.py` |
| `osal` | `osal_generator.py`, `code_templates.py` |
| `statable_all` | `c_code_generator.py` |
| `_run.c` | `c_code_generator.py` |

### ルール分類

| 分類 | 条件 |
|------|------|
| `suppressed` | `SUPPRESSED_RULES`（10ルール）に該当 |
| `misra-active` | `misra-c2012-*` で `suppressed` 以外 |
| `non-misra` | `NON_MISRA_IDS`（4種）に該当 |
| `other` | 上記以外 |

### `SUPPRESSED_RULES`（10ルール）

```
misra-c2012-8.4, 8.7, 8.9, 5.9, 15.5, 15.7, 2.3, 2.4, 2.5, 21.6
```

**⚠ `suppressions.txt` との不一致**：
- `suppressions.txt` にあり、`SUPPRESSED_RULES` にない：`11.5`, `18.4`
- `SUPPRESSED_RULES` にあり、`suppressions.txt` にない：`21.6`

### 使用例

```bash
python tools/analyze_misra_impact.py \
  --xml misra_report/cppcheck_raw.xml \
  --out misra_report/impact.md \
  --csv misra_report/impact.csv
```

### `impact.md` の形式（抜粋）

```markdown
# MISRA Impact Analysis

## Totals by category
| Category | Count |
|----------|------:|
| misra-active | 10 |
| non-misra | 9 |
| suppressed | 4 |

## Codegen sources to modify (ranked)
| Codegen source | Total hits | Top rules |
|----------------|-----------:|-----------|
| `codegen/osal_generator.py` | 6 | 11.5(4), 18.4(2) |
| ...

## Suggested action order
| # | Rule | Action | Hits |
|---|------|--------|-----:|
| 1 | misra-c2012-17.3 | Add missing includes... | 0 |
```
