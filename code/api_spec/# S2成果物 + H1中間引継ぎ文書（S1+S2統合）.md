# Part B: §6 ユーティリティAPI章ドラフト

## 6.1 XmlIO（`statable/xml_io.py`）

### 6.1.1 モジュール概要

プロジェクト全体（複数タブのStateMachine、GlobalDefinitions、共有ライブラリ、プロジェクト設定）のXML永続化。

**XML形式**：UTF-8、`ET.indent(tree, space="    ")` による整形

**依存関係**

```python
# statable/xml_io.py の先頭
try:
    from statable_gui.libcntrl.role_function_library import (RoleFunctionLibrary, RoleFunction as LibRoleFunction)
    from statable_gui.libcntrl.condition_library import (ConditionLibrary, ConditionTemplate)
    from statable_gui.libcntrl.literal_library import (LiteralLibrary, LiteralDefinition)
except ImportError:
    RoleFunctionLibrary = ConditionLibrary = LiteralLibrary = None
    ...
```

**⚠ 重要**：`statable/` 層が `statable_gui.libcntrl` を参照する**逆依存**（SPEC_OVERVIEW §2.2の依存方向に反する）。`ImportError` 時は `None` でフォールバックし、SDK単体利用時はライブラリ関数が `None` を返す。

**ロガー**：`logging.getLogger("statable.xml_io")`

### 6.1.2 `project_to_xml`

プロジェクト全体をXMLファイルに保存する。

**シグネチャ**

```python
def project_to_xml(
    tabs: List[Tuple[str, StateMachine]],
    global_defs: GlobalDefinitions,
    filepath: str,
    role_function_library=None,
    condition_library=None,
    literal_library=None,
    project_settings: Optional[dict] = None,
) -> None
```

**パラメータ**

| 名前 | 型 | 必須 | デフォルト | 説明 |
|------|-----|------|-----------|------|
| `tabs` | `List[Tuple[str, StateMachine]]` | ○ | – | `(タブ名, StateMachine)` のリスト |
| `global_defs` | `GlobalDefinitions` | ○ | – | グローバル定義 |
| `filepath` | `str` | ○ | – | 出力先XMLパス（UTF-8） |
| `role_function_library` | `RoleFunctionLibrary \| None` | – | `None` | 共有ロール関数ライブラリ |
| `condition_library` | `ConditionLibrary \| None` | – | `None` | 共有条件ライブラリ |
| `literal_library` | `LiteralLibrary \| None` | – | `None` | 共有リテラルライブラリ |
| `project_settings` | `Optional[dict]` | – | `None` | プロジェクト設定（後述） |

**`project_settings` のキー**

| キー | 型 | デフォルト | 説明 |
|------|-----|-----------|------|
| `project_name` | `str` | `"MyProject"` | プロジェクト名 |
| `table_type` | `str` | `"array"` | テーブル型 |
| `generation_style` | `str` | `"table_driven"` | 生成方式 |
| `os_type` | `str` | `"non_rtos"` | OS種別 |
| `folder_structure` | `str` | `"by_type"` | フォルダ構成 |
| `include_dir_name` | `str` | `"include"` | include ディレクトリ名 |
| `source_dir_name` | `str` | `"src"` | src ディレクトリ名 |
| `common_dir_name` | `str` | `"common"` | common ディレクトリ名 |
| `project_dir_name` | `str` | `"project"` | project ディレクトリ名（未使用） |
| `generate_super_include` | `bool` | `True` | スーパーinclude生成 |
| `super_include_file` | `str` | `"statable_all.h"` | スーパーincludeファイル名 |
| `external_includes` | `List[str]` | `[]` | 外部include |
| `external_includes_in_super` | `bool` | `True` | super への外部include |
| `external_includes_in_role` | `bool` | `True` | role への外部include |
| `external_includes_in_transitions` | `bool` | `False` | transitions への外部include |
| `external_includes_in_common` | `bool` | `False` | common への外部include |
| `max_consecutive_pending_events` | `int` | `16` | 連続pendingイベント上限 |

**戻り値**：なし

**例外**

- `IOError` / `OSError`：ファイル書込み失敗時
- `ET.ParseError` 系：XML構築失敗時（通常は発生しない）

**使用例**

```python
from statable.xml_io import project_to_xml
from statable import StateMachine, GlobalDefinitions

sm = StateMachine()
# ... 構築 ...
project_to_xml(
    tabs=[("Application", sm)],
    global_defs=GlobalDefinitions(),
    filepath="project.xml",
    project_settings={"project_name": "Demo"},

```

**備考**

- `project_settings` が `None` の場合、`<ProjectSettings>` 要素は省略される
- `role_function_library` 等が全て `None` の場合、`<SharedLibraries>` 要素は省略される
- **`super_include_dir` は保存されない**（SPEC_OVERVIEW C-10 と一致）

## 6.2 MermaidGenerator（`statable/mermaid_gen.py`）

### 6.2.1 `generate_mermaid`

StateMachineからMermaid `stateDiagram-v2` 文字列を生成する。

**シグネチャ**

```python
def generate_mermaid(sm: StateMachine) -> str
```

**パラメータ**

| 名前 | 型 | 必須 | 説明 |
|------|-----|------|------|
| `sm` | `StateMachine` | ○ | 対象ステートマシン |

**戻り値**：`str` — Mermaid形式の複数行文字列

**例外**：なし

**出力形式**

```
stateDiagram-v2
    direction LR
    [*] --> InitialState
    Source --> Target : Title (Event) [Condition] [Commit]
    Source --> ElseTarget : (Event) else [Commit]
    note right of State : internal: Title (Event) [Condition]
```

**ラベル構築規則**（`_build_label`）

| 要素 | 条件 | 出力例 |
|------|------|--------|
| Title | `title` が `"(untitled transition)"` 以外 | `Startup` |
| Target名 | `title` が空 or 未設定のtransition | `Active` |
| `(internal)` | `title` も `target` も空 | `(internal)` |
| `(Event)` | `event` が非空 | `(START)` |
| `[Condition]` | `condition` が非空（50文字に切り詰め） | `[err_code != 0]` |
| `[Commit]` | `early_return == True` | ` [Commit]` |

**サニタイズ**（`_sanitize_label`、ASCII限定）

| 元 | 置換後 |
|----|--------|
| `:` | `-` |
| `[` | `(` |
| `]` | `)` |
| `"` | `'` |
| `` ` `` | `'` |
| `\n` / `\r` | ` `（スペース） |

**条件の切り詰め**（`_truncate_condition`）

- 1行目のみ使用（2行目以降は ` ...` で省略）
- 50文字超過時は `...` 付与

**使用例**

```python
from statable.mermaid_gen import generate_mermaid

mermaid = generate_mermaid(sm)
print(mermaid)
# stateDiagram-v2
#     direction LR
#     [*] --> Idle
#     Idle --> Active : Startup (START)  [Commit]
#     Active --> Idle : Stop (STOP)  [Commit]
#     ...
```

**備考**

- `else_target` は**別エッジ**として出力（`stateDiagram-v2` は破線非対応のため、`else` ラベルで区別）
- `entry` / `exit` は**出力しない**（メタデータ扱い）
- `target` が空（internal actionのみ）の場合、`note right of ... : internal: ...` として出力
