## 付録: 英語化の原則

1. **コード識別子は変更しない**（変数名 / 関数名 / クラス名は Python のため英語済み）
2. **文字列リテラル・コメント・docstring のみ変換**
3. **日本語の助詞は削除して英語の語順に組み替え**
   - 例: 「状態を初期化する」→ `Initialize state` または `Initialize the state`
4. **C コードコメントは英語の慣習に従う**
   - `/* Initialize state */`
   - `/** @brief Initialize state */`
5. **GUI ラベルは簡潔に**
   - 「グローバル変数・イベントフラグ定義を開く」→ `Open Global Definitions`
