commit-begin
tools: add git_runner.py for scripted Git operations

Motivation:
  Complex Git workflows (multi-line commit messages, staged
  sequences, quote-heavy PowerShell escapes) were error-prone
  when driven manually from PowerShell. This tool lets the
  operations live in a plain text file (git_ops.txt) that is
  read and executed sequentially.

Usage:
  python tools/git_runner.py --dry-run
  python tools/git_runner.py

Features:
  - commit-begin/commit-end blocks for multi-line messages
  - reset-hard guarded by an interactive confirmation
  - --dry-run, --continue-on-error, --list options
  - Unknown commands fail fast before any git call
commit-end
