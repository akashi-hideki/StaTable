## Slide 2: 課題（Problem）

### 組込み開発の現状

- 手作業での C コード作成 → 時間とコスト
- MISRA C 準拠の確認 → 多大な工数
- 状態遷移の可視化 → 困難
- コード再生成時の手書きコード消失 → 致命的

### 市場の要求

- MISRA C:2025 新規制
- UNECE R155/R156 サイバーセキュリティ
- 中国 GB 標準の機能安全要件

---

## Slide 3: 解決策（Solution）

### StaTable の価値提案

1. **表駆動型コード生成**
   状態 × 事件行列 → C99 コード自動生成

2. **MISRA C:2012 準拠**
   cppcheck 公式 MISRA アドオンで検証済み

3. **ユーザーコード保護**
   marker 方式で再生成時も手書きコードを保持

4. **Eclipse 統合**
   既存ツールチェーンへのシームレスな統合
