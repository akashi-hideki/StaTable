## 1. 摘要

StaTable 是一款面向嵌入式系统的 MISRA C:2012 状态机设计与 C 代码生成工具。
它使嵌入式工程师能够以可视化方式设计复杂状态机，并自动生成符合 MISRA
规范、可直接投入生产的 C99 代码。

**核心价值:**
- **零依赖核心** — 无第三方运行时库
- **MISRA C:2012 合规** — 通过 cppcheck 官方插件验证
- **Eclipse 集成** — 可直接接入现有工具链
- **QEMU 验证** — ARM Cortex-M4 实机链接已验证
- **多语言** — 日本語 / English / 简体中文
- **Apache-2.0 许可** — 可商业使用

**目标市场**: 中国和日本的嵌入式工程师及家电制造商，特别是汽车、
医疗和工业设备领域。

**当前状态**: v3.5.3 已于 2026-10-11 在 PyPI 和 GitHub 发布。
- 49 个测试套件 / 1873 PASS / 0 FAIL

## 2. 技术概述

### 2.1 架构

StaTable 采用七层状态机架构:

1. **Application** — 顶层系统逻辑
2. **MwMicrowave** — 微波控制中间层
3. **MwOven** — 烤箱控制中间层
4. **MwGrill** — 烧烤控制中间层
5. **MwSteam** — 蒸汽控制中间层
6. **DriverInput** — 传感器 / RX / 门安全输入
7. **DriverOutput** — 加热器 / 风扇 / TX 输出

分层设计允许各子系统的独立开发和测试，层间接口清晰。

### 2.2 代码生成

StaTable 从状态 × 事件矩阵生成 C99 代码:

- **表驱动分派** — 针对嵌入式 MCU 优化
- **状态动作** — 完整支持 UML Entry / Exit / Do 语义
- **用户代码保护** — 基于标记的合并器在重新生成时保留手写代码
- **文件级标记** — `[[STABLE_USER_CODE_START]]` /
  `[[STABLE_USER_CODE_END]]` 块用于文件作用域用户代码

### 2.3 验证

- **35 条验证规则**，涵盖 11 个类别
- **MISRA C:2012 合规** — cppcheck 官方 MISRA 插件
- **ARM Cortex-M4 链接验证** — 在真实硬件上验证通过
- **QEMU 执行** — 使用 netduinoplus2 仿真进行 CI

### 2.4 接口

- **GUI** — 基于 PySide6，中文/英文/日文界面
- **CLI** — `statable-cli generate` / `validate`
- **Python SDK** — 21 个公开符号，供程序化使用
- **Eclipse 安装器** — 用于 Eclipse 4.41 集成的独立工具
