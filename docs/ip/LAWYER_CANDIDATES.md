## 4. 初回相談のチェックリスト

### 4.1 事前準備

- [ ] 相談書面（`docs/ip/LAWYER_CONSULTATION.md`）を送付
- [ ] 添付資料（技術白書、OSS、Git履歴）を整理
- [ ] 相談内容を質問形式で整理
- [ ] 費用を事前確認

### 4.2 相談時に確認すべき事項

- [ ] 会社に知られずに相談できるか
- [ ] 秘密保持の方法
- [ ] 想定される法的リスク
- [ ] 取るべき次のアクション
- [ ] 費用の見積もり

### 4.3 相談後のフォロー

- [ ] 助言内容をメモ
- [ ] 追加で必要な資料を確認
- [ ] 次のステップを整理
